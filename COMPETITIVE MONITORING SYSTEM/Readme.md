\#\# 1\. Project Overview  
This repository contains the Core AI Engine for the Bibica Market Intelligence system. Utilizing a Decision Tree algorithm (White-box AI), the system automates market data analysis to identify dynamic pricing tipping points and trigger non-price defense mechanisms, mitigating the risk of margin-eroding price wars.

\#\# 2\. Repository Structure  
\- \`data/product.csv\`: Input dataset containing market metrics (e.g., discount percentages, sales volume).  
\- \`master\_pipeline.py\`: Main execution script encompassing data preprocessing, model training, and action triggers.  
\- \`requirements.txt\`: Python dependencies required for execution.
